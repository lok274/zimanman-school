# 字慢慢

供學校平板使用嘅繁體中文筆順練習。孩子先揀詞語，再逐字看示範、跟寫及收起字形試寫。介面有可選粵語聲音、朗讀邀請、起筆提示、休息及老師協助略過。程式不錄音，不記學生姓名，不設帳戶。

直接開啟 `dist/standalone.html`，可用內置六項詞語。亦可用任何靜態網頁伺服器提供 `dist/`。新增字詞可能需要上網載入字庫。

執行以下指令檢查邏輯及重新產生單檔版。

```powershell
node --test tests/*.test.cjs
node scripts/standalone.cjs
node dist/data/self-check.mjs
```

老師工具可編輯詞語及每節範圍。預設兩項，最多六項。紀錄只留喺目前瀏覽器。共用平板使用者可能查看，清除瀏覽器資料後亦會遺失。瀏覽器拒絕儲存時仍可練習，畫面會說明未儲存。

「自己完成」只代表該次無開提示完成平板筆畫配對，不能證明默寫、紙筆書寫或學習成效。筆畫配對容許較大偏差，只供練習回饋，並非書寫字形評分。紀錄保留之前提示、重試、未完成及老師略過嘅嘗試。收起字形期間亦會遮住介面其他位置嘅目標字；開老師工具則先計為提示。重開網頁會將該分頁未完成嘅上一節列為未完成，再開始新一節。

初始十一個字已附本機資料。`草`、`密`、`來` 按教育局圖示調整，詳見 `dist/data/provenance.json` 及 `NOTICE.txt`。字形風格仍可能不同，請按學校教法核對。新增字未經香港逐畫核對。字庫採 Arphic Public License。Hanzi Writer 固定為 3.5.0，採 MIT 授權。單檔版包括授權全文。

原生粵語語音視裝置而定。沒有粵語聲音時會邀請老師朗讀，不改播普通話。未做真實 iPad、觸控筆或學生試用；瀏覽器測試亦不能證明 ADHD 或讀寫障礙學習成效。
