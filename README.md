# 寫字樂

練習入口依次為「二年級」→「2上1」→「第一課《爸爸的鬍鬚》」→「練習1／練習2」→選字。測驗入口直接選組別。老師套用的自訂詞語與指定字位同樣適用。

供學校平板使用嘅繁體中文筆順練習。首頁有「練習」及「測驗」兩個大按鈕，使用同一份老師已套用選字。揀好組別後，再揀詞語。練習先看示範、跟寫及收起字形試寫。測驗直接進入空白書寫格。介面有可選粵語聲音、起筆提示、休息及老師協助略過。老師和學生都不用帳戶；班級測驗使用暱稱。

GitHub Pages 網頁入口為 [寫字樂](https://lok274.github.io/zimanman-school/)，任何人都可透過連結開啟，不需要 GitHub 帳戶。原始碼放喺 [lok274/zimanman-school](https://github.com/lok274/zimanman-school)。

Android 平板請用更新版 Chrome，iPad 請用 Safari，直接開啟上述 HTTPS 網址。iPad 需要 iPadOS 15.4 或以上，因為老師工具及休息視窗使用該版本開始支援嘅 [原生 dialog 功能](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。書寫區可用手指或觸控筆操作，實際觸控筆及掌壓排除表現需要在學校裝置測試。粵語聲音視裝置及瀏覽器有冇提供粵語語音而定，請在上堂前按「聽詞語」確認。

直接開啟 `dist/standalone.html`，可用內置六項詞語。部分平板嘅檔案預覽器未必執行下載嘅 HTML，平板建議用上面嘅網站。亦可用任何靜態網頁伺服器提供 `dist/`。新增字詞可能需要上網載入字庫。

老師可在「課堂詞語」旁按「粵語輸入」，每次講一項詞語。核對或修改「待確認詞語」，再按「確認加入」，只會加到當前文字框。之後仍須按「更新可選詞語」、揀範圍及「套用並返回首頁」。每項只接受 1 至 8 個中文字，不會自動拆詞、改同音字或轉換繁簡。重複詞語不會再加入。關閉老師工具、轉到背景或離開網頁會停止收音並捨棄未確認內容。

只有老師主動按「粵語輸入」才會要求用咪，每次最長 20 秒，不會自動重試。程式使用瀏覽器提供嘅語音辨識，指定 `yue-Hant-HK`；瀏覽器供應商可能經網絡處理聲音，不能保證離線或只在裝置處理。程式不保存或自行上傳錄音，只把老師確認嘅文字加到詞語框。瀏覽器沒有語音辨識、拒絕用咪或辨識失敗時，仍可直接打字或用系統鍵盤語音輸入。實體 Android 平板及 iPad 嘅收音、粵語辨識和權限流程尚未驗證。

內置六項詞語使用純白背景嘅 AI 生成寫實圖片，並非實地拍攝照片。詞語卡及練習頁共用同一圖片；新增詞語或圖片未能載入時顯示原有圖示。單檔版已嵌入六張圖片。圖片內容、檔案及完整生成提示詞見 [圖片說明](圖片說明.md)。

上堂前，老師先開「老師工具」，在各詞語內逐字選擇，再按「套用並返回首頁」。預設選取全部內置詞語嘅字，老師可縮窄範圍；可選 1 至 6 項詞語內最多 48 個字。老師工具會顯示已選字數。本機練習及測驗按已套用嘅詞語順序平均分兩組，單數時第一組多一項，空嘅第二組不能選。內置第一組為「粗、濃、鬍鬚」，第二組為「密、剪草機、推來推去」。班級測驗保留老師固定嘅全份題目，不分組。

詞語卡及書寫標題顯示完整詞語；每頁書寫格只處理一個字。只選「推來推去」第四字時，完整詞語仍然顯示，但只會練「去」。同字出現在不同位置會分開練，例如第一、三字嘅「推」。完成一字後按下一步，會接住同一詞語下一個指定字；全詞處理後才返回選詞。全詞處理後，卡片會顯示完成或待練印章。獨立試寫仍會隱藏詞語及介面其他位置嘅目標字。老師選字及紀錄保留完整詞語和原有位置，未選嘅字不會列為待練。老師略過仍分開記錄，並非完成書寫。最後一個指定字處理後，孩子按下一步才看紀錄。完成後可揀一個練過嘅字用紙筆試寫。

練習「睇筆順」時，可按「上一字」或「下一字」直接睇同一詞語其他已選字嘅示範，毋須先寫完目前字。按鈕顯示將會睇嘅字，只在有相鄰指定字時出現。手動轉字後要自行按播放。播放完整字形後，會自動播放同一詞語下一個已選字，到最後一字就停止。暫停後可繼續；單畫示範不會自動轉字。休息、開老師工具、轉到背景或離開網頁會停止連播，返回後要自行按播放。「到我跟住寫」會練目前示範嘅字。睇示範不會新增書寫、完成或略過紀錄，未寫嘅字仍然待練。測驗沒有示範導航。播放、重播及單畫示範共用 `strokeAnimationSpeed: 0.45`，每畫之間仍停頓 520 毫秒。

練習區上方有獨立「聽指令」按鈕，只在孩子按下時朗讀畫面上的同一句指令。「聽詞語」仍用來讀詞語及目標字，兩者用途分開。聽操作指令不算書寫提示，不會改動嘗試結果。程式只使用裝置提供的粵語聲音，缺少語音、瀏覽器封鎖或播放錯誤時顯示文字說明，不改播普通話。轉步驟、休息、開老師工具、轉到背景或離開網頁會停止語音。練習事件回饋出現後會收起上方舊指令，「聽指令」改讀目前可見的短句，並停止仍在播放的舊指令。相同步驟的筆畫回饋不會打斷詞語讀音。實際可聽度仍須在課堂平板確認。

練習頁將重播、單畫示範、字形提示、重試、音效及畫面設定收進同一個「更多工具」。詞語讀音、聽指令、當前筆畫提示、休息及返回仍可直接操作。已刪去口號、例句及重複說明。每次開啟預設使用「精簡畫面」，收起圖片及較長說明，保留放大的目標字、詞語語音、目前步驟、操作指令、書寫格及所有必要控制。橫向平板會把書寫格和操作按鈕並排。開啟「更多工具」，按「精簡畫面」可切回完整背景，再按可收起。切換只改顯示，不重開書寫格、不重設筆畫、不新增提示或嘗試。獨立試寫時兩種畫面同樣隱藏目標字。休息仍在練習區上方，返回仍在頁尾左邊。

練習標題及操作指令各自置中，字體均比原有尺寸加大 10pt。平板精簡畫面按可用高度調整方形書寫格；展開工具、完整畫面或較小視窗仍可正常捲動。

練習時可用頁尾左邊嘅返回按鈕退回上一個步驟。「自己試」及完成畫面返回同一個字嘅新一輪跟寫，跟寫返回睇筆順，睇筆順或載入畫面返回選字。老師若在字形未載入前略過，返回時會先重新載入。返回後由該步驟起點重新練習。之前嘅提示、未完成嘗試及完成結果會保留，返回本身不會得到完成獎勵。

「休息一下」放喺練習區上方，使用有邊框嘅大按鈕，字體比原本增加 6 pt。休息後按「我準備好喇」會返回原本步驟，保留練習進度。

跟寫先顯示「先寫一畫。」。第一畫被書寫工具接納後，書寫格下方會顯示「你開始咗，第一畫完成！」。寫錯顯示「再試呢一畫。」，原有提示按鈕改為「睇一畫再試」；同一畫錯兩次仍會自動示範，之後請孩子再試。寫錯後成功優先顯示「你再試成功咗！」。已接納筆畫及畫數保留，毋須由頭重寫。其餘成功筆畫繼續顯示進度。求助、重新試或休息都不扣分，程式亦不設分數、連勝或排名。跟寫完成、有提示完成、自己完成各有清楚文字，並有同樣短暫嘅勾號慶祝。減少動態效果設定會保留靜態勾號。這些回饋只描述當次操作，不代表已掌握筆順或專心程度。

練習的回饋列只加一個小型「★ 數量」。本節每個指定位置首次完成跟寫或自己試，便計一顆；用過提示亦計。同一位置再寫、重試或由跟寫進入自己試不會重複計，同字在不同指定位置則分開計。寫錯不扣星；只看示範、未完成、放棄或老師略過不會加星。測驗、首頁、選字及紀錄頁不顯示，開新一節重新計算。星數沿用現有完成紀錄，不增加儲存欄位，亦不改動提示、錯誤或略過紀錄。星只表示完成練習，不能當作掌握程度或努力量度。


測驗保留目標字及原詞圖片，精簡畫面亦會顯示。書寫格沒有白色字形、起筆點、示範或筆畫提示；答對後仍保留孩子原本寫下的筆跡，不會換成標準字形。寫錯一畫會顯示「再試呢一畫。」文字，重新落筆或寫對後收起。全部筆畫完成才顯示綠圈，等孩子按下一步；老師略過不顯示綠圈。筆畫配對仍按筆順即時判斷，不是最後交卷才判斷，也不是字體美觀評分。測驗的返回鍵回到選字，重試會清空本次書寫格，但保留之前的嘗試和完成結果。

測驗右下方顯示本次測驗嘅有效書寫時間，老師紀錄亦保留逐次嘗試。畫面更新只讀現有時鐘，不寫入儲存。從書寫格真正準備好開始計算，排除載入、休息、老師工具、背景、選字及結果畫面的時間。每個字會加總所有有計時的嘗試，包括重試前及中途離開的時間。未開始或無法計時的部分會如實標示，不能當成零秒或完整總時間。練習不計時。關閉網頁會保存當時累積時間，重開不會加上離開期間；強制終止瀏覽器可能遺失最後一次未保存的片段。

班級測驗用獨立嘅 `classroom-service/` Worker 與 D1 儲存跨平板成績。老師直接開班級服務嘅 `/teacher` 頁面即可用內置六項詞語開班，不用登入或管理連結。亦可先在學生頁揀範圍，再按「用以上範圍開班級測驗」。老師頁會保存今次題目和開班要求，重新開頁或重試不會重複開班；按「開新一班」才建立另一份要求。同學按首頁「加入班級測驗」，輸入班級碼及暱稱。該班全部同學使用同一份固定題目；本機老師設定不會改動班級題目。最後一字處理後按「完成測驗」，成功交卷便在同一分頁自動開 `leaderboard.html`，顯示前三名展示、完整班級榜及個人最佳。寫字途中不顯示班級排名。交卷失敗會保留完成頁及相同待交紀錄，按重試後再跳轉。

全份測驗先比總錯誤次數，再比有效書寫總時間；所有重試及重寫都計算，合計後四捨五入至 0.1 秒。每位只列最好一次，同分排名為 1、1、3。跳過題目或任何嘗試缺少計時，只可交不排名回條；有回條後仍可看全班結果。未處理全部題目不能看榜。排行榜每 5 秒更新一次，只在前景進行；最多自動更新 120 次，手動更新可重新開始。背景及離頁會停止輪詢。

暱稱與參加憑證只代表目前班級嘅身份，並非已驗證學生帳戶。共用平板要明確選繼續或「換下一位同學」；重新開頁不會自動當作原同學，剛完成測驗嘅一次轉頁則毋須再確認。憑證放喺同源分頁儲存，伺服器只存雜湊。同名不會接管他人紀錄，換平板或遺失憑證亦不能靠暱稱取回。拒絕分頁儲存時不會先建立雲端參加身份，本機練習仍可使用。本機測驗的「此瀏覽器最佳」只比較最近 40 筆相同題目，不能稱為某位學生的最佳。

班級最多 100 人，每人 20 次終結紀錄，每個開班瀏覽器最多同時 10 班，整個服務最多同時 100 班；24 小時後拒絕讀寫。公開免登入開班可能被佔滿名額，屆時要等舊班到期。建立新班時會逐批清理已到期班級及結果，並不承諾精確刪除時間。不存學生真名、電郵、筆跡或逐畫座標。暱稱及成績會存到班級服務；其他已完成同班測驗嘅同學可看。瀏覽器提交嘅時間和錯誤可被偽造，只供課堂活動。

老師嘅開班權限由瀏覽器自動產生及保存，毋須輸入密碼或保管連結。伺服器只存權限雜湊。老師頁用獨立介面查看自己開嘅班，學生仍須完成全份測驗才可看榜。清除開班瀏覽器資料後，無法取回原班管理權限；共用同一個瀏覽器嘅其他使用者亦可用該權限。新班不會改動舊班題目或成績。

服務地址設定為 `https://zimanman-classroom-1023.lokyau65.chatgpt.site`。原始碼提交與實際部署分開，部署紀錄才代表上線狀態；未能連線時會如實顯示錯誤。單檔版保留本機練習及測驗，班級功能導向網上學生頁面。服務 API、建置及本機 D1 驗證見 [classroom-service/README.md](classroom-service/README.md)。

目前測驗字的已接納筆跡只暫存記憶體。休息、老師工具及背景切換返回同一字時保留筆跡，調整書寫格尺寸時按比例重畫。重試、換字或新模式會使用空白書寫格。筆跡不會存入歷史，重新載入網頁亦不會還原畫面。首頁及組別頁不會建立練習紀錄，揀組別後才建立該組嘅一節。本機選詞頁返回會結束目前一節並回組別頁，再返回首頁。左上角品牌及完成頁返回會結束目前一節並回首頁。老師未套用或取消的草稿不影響兩個模式的已套用選字。

「完成提示聲」每次開網頁都預設關閉，由學生自行開啟。開啟後只在完成一個字時播放短聲，普通筆畫不會發聲。裝置靜音、瀏覽器限制或音效未準備好時，畫面回饋照常，程式不會之後補播。休息、開老師工具、轉步驟、轉到背景或離開網頁會停止正在播放嘅提示聲及慶祝動態。實際音量及聲音能否播放，需要在學校平板試用。

推送至 `main` 會自動執行 `.github/workflows/pages.yml`。流程先用 Node.js 24 執行現有行為測試及字庫檢查，全部通過後才將 `dist/` 部署到 GitHub Pages。GitHub 儲存庫嘅 Pages 發佈來源須設為 GitHub Actions。亦可在 Actions 頁面手動執行流程。網站不需要伺服器程式或額外建置。

`index.html` 與 `leaderboard.html` 的本機程式及樣式網址包含內容版本，避免新版頁面讀到舊快取。更改後執行 `node scripts/version-assets.cjs`；版本為統一 LF 換行後 SHA-256 的首 12 字。單檔產生器可處理這些版本網址。

執行以下指令檢查邏輯及重新產生單檔版。

```powershell
node scripts/version-assets.cjs
node --test tests/*.test.cjs
node classroom-service/build.mjs
node scripts/standalone.cjs
node dist/data/self-check.mjs
```

老師工具可編輯詞語及每節指定字次。新紀錄使用版本 3，分開記錄練習及測驗，並只記指定位置。原有版本 1 的完整範圍及版本 2 的已選位置紀錄仍可讀取，不會改寫為新版。套用新設定前會先核對完整選字設定，錯誤或零選字不會結束目前有效練習。本機歷史只留喺目前瀏覽器及網站網址。共用平板使用者可能查看，清除瀏覽器資料後亦會遺失。原本 Sites 網址嘅歷史不會自動轉移到 GitHub Pages，不同平板或瀏覽器之間亦不會同步本機歷史；跨平板班級榜則另外儲存已交卷結果。瀏覽器拒絕儲存時仍可練習，畫面會說明未儲存。

「自己完成」只代表該次無開提示完成平板筆畫配對，不能證明默寫、紙筆書寫或學習成效。筆畫配對容許較大偏差，只供練習回饋，並非書寫字形評分。紀錄保留之前提示、重試、未完成及老師略過嘅嘗試。收起字形期間亦會遮住介面其他位置嘅目標字；練習的獨立試寫開老師工具則先計為提示。測驗開老師工具會暫停書寫及計時，不會開提示。重開網頁會將該分頁未完成嘅上一節列為未完成，然後返回首頁。
