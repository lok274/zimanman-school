# 寫字樂

模組單體架構、資料流、模組責任和擴充方法見 [MODULE_ARCHITECTURE.md](MODULE_ARCHITECTURE.md)。

練習及小挑戰各層選單和書寫頁的返回按鈕放在頁尾左邊，至少 200 × 72 像素及 24 像素字體；預設平板詞語卡或書寫格、主要操作與返回按鈕同屏顯示，手機、放大畫面或額外內容可正常捲動。

練習及小挑戰入口均依次為「二年級」→「2上1」→「第一課《爸爸的鬍鬚》」→揀組別→選字。練習組別為「練習1／練習2」，小挑戰組別為「小挑戰1／小挑戰2」。老師套用的自訂詞語與指定字位同樣適用。

供學校平板使用嘅繁體中文筆順練習。首頁有「練習」及「小挑戰」兩個大按鈕，使用同一份老師已套用選字。揀好組別後，再揀詞語。練習揀詞語後直接進入「自己寫」，需要時可按「跟住寫」。有內置用途的詞語預設做標籤，其他詞語顯示一般作品卡；舊紀錄的介紹句仍然保留。小挑戰顯示淡色完整字形，按開始後自由書寫及逐詞計時。介面保留詞語聲音、提示與擦掉前一筆。老師和學生都不用帳戶；班級小挑戰使用暱稱。

GitHub Pages 網頁入口為 [寫字樂](https://lok274.github.io/zimanman-school/)，任何人都可透過連結開啟，不需要 GitHub 帳戶。原始碼放喺 [lok274/zimanman-school](https://github.com/lok274/zimanman-school)。

Android 平板請用更新版 Chrome，iPad 請用 Safari，直接開啟上述 HTTPS 網址。iPad 需要 iPadOS 15.4 或以上，因為老師工具視窗使用該版本開始支援嘅 [原生 dialog 功能](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。書寫區可用手指或觸控筆操作，實際觸控筆及掌壓排除表現需要在學校裝置測試。粵語聲音視裝置及瀏覽器有冇提供粵語語音而定，請在上堂前按喇叭圖示確認。

直接開啟 `dist/standalone.html`，可用內置六項詞語。部分平板嘅檔案預覽器未必執行下載嘅 HTML，平板建議用上面嘅網站。亦可用任何靜態網頁伺服器提供 `dist/`。新增字詞可能需要上網載入字庫。

老師可在「課堂詞語」旁按「粵語輸入」，每次講一項詞語。核對或修改「待確認詞語」，再按「確認加入」，只會加到當前文字框。之後仍須按「更新可選詞語」、揀範圍及「套用並返回首頁」。每項只接受 1 至 8 個中文字，不會自動拆詞、改同音字或轉換繁簡。重複詞語不會再加入。關閉老師工具、轉到背景或離開網頁會停止收音並捨棄未確認內容。

只有老師主動按「粵語輸入」才會要求用咪，每次最長 20 秒，不會自動重試。程式使用瀏覽器提供嘅語音辨識，指定 `yue-Hant-HK`；瀏覽器供應商可能經網絡處理聲音，不能保證離線或只在裝置處理。程式不保存或自行上傳錄音，只把老師確認嘅文字加到詞語框。瀏覽器沒有語音辨識、拒絕用咪或辨識失敗時，仍可直接打字或用系統鍵盤語音輸入。實體 Android 平板及 iPad 嘅收音、粵語辨識和權限流程尚未驗證。

內置六項詞語使用純白背景嘅 AI 生成寫實圖片，並非實地拍攝照片。詞語卡及練習頁共用同一圖片；新增詞語或圖片未能載入時顯示原有圖示。單檔版已嵌入六張圖片。圖片內容、檔案及完整生成提示詞見 [圖片說明](圖片說明.md)。

上堂前，老師先開「老師工具」，在各詞語內逐字選擇，再按「套用並返回首頁」。預設選取全部內置詞語嘅字，老師可縮窄範圍；可選 1 至 6 項詞語內最多 48 個字。老師工具會顯示已選字數。本機練習及測驗按已套用嘅詞語順序平均分兩組，單數時第一組多一項，空嘅第二組不能選。內置第一組為「粗、濃、鬍鬚」，第二組為「密、剪草機、推來推去」。班級測驗保留老師固定嘅全份題目，不分組。

每頁只寫老師選取的一個位置。同字出現在不同位置會分開練，例如「推來推去」第一、三字。完成一字後，孩子按下一步才接住同詞下一個指定字，並由「自己寫」開始。全詞處理後必定先看作品卡，再選下一詞或看紀錄。作品卡使用孩子當次成功書寫的原筆跡，未選的字標示「配字」，略過或缺失筆跡分開標示。介紹句只在指定位置放入一次完整詞語。跟寫完成記為有提示完成，不強制再寫一次。自己寫沒有開提示才記為這次自己完成，不代表已掌握。

舊版練習紀錄若停在「睇筆順」，仍可按「上一字」或「下一字」睇同一詞語其他已選字嘅示範。手動轉字後要自行按播放；完整播放可連播下一個已選字。開老師工具、轉到背景或離開網頁會停止連播。新練習不會進入示範步驟。測驗沒有示範導航。

練習頁保留完整目標詞語、圖片及喇叭按鈕。喇叭按鈕只有圖示，讀屏名稱會按粵語聲音是否可用而更新。自己寫時讀全詞及指定字位，格內只顯示孩子已寫的筆跡。沒有粵語聲音或播放失敗時顯示文字說明，不改播普通話。開老師工具、轉到背景或離開網頁會停止語音。

版本 4 練習固定使用精簡畫面，保留目標詞語、圖片、喇叭、書寫格、主要操作、直接可見的「擦掉前一筆」及返回。擦除只移走同一次未完成練習最後一筆，保留之前筆畫、錯誤、提示與開始時間；零筆時停用，完成後不提供。擦除後若書寫格載入失敗，可按「再載入書寫格」繼續同一次練習。舊版練習保留原有遮字規則，沒有新增擦除功能。小挑戰原有的單筆撤回亦顯示為「擦掉前一筆」。

練習標題及操作指令各自置中，字體均比原有尺寸加大 10pt。平板精簡畫面按可用高度調整方形書寫格；展開工具、完整畫面或較小視窗仍可正常捲動。

頁尾返回按鈕保留在左邊。自己寫返回選詞；由自己寫開啟的跟寫返回同一次自己寫，已接納筆跡、進度、錯誤及提示紀錄都保留。完成字後返回可獨立重寫同一字；作品卡返回可獨立重寫最後一個指定字。原先成功的筆跡直到另一次成功才換掉。中途離開的嘗試記為未完成。舊版紀錄維持原本的示範、跟寫、自己試含義。

預設十一個字的跟寫按已核對的筆順顯示部件，未寫部件較淺，當前部件較深，已接納筆畫保留。來字整體練習，不強行拆件。首次寫錯或要求單畫提示後，橙點旁顯示短起筆箭嘴；短點或過早轉彎只保留起點及原有示範。其他字或筆畫數不符時保留原有整字跟寫，先顯示「先寫一畫。」。第一畫被書寫工具接納後，書寫格下方會顯示「你開始咗，第一畫完成！」。寫錯顯示「再試呢一畫。」；跟寫同一畫錯兩次會自動示範。自己寫錯兩次只強調「跟住寫」按鈕，必須孩子按下才開引導；原筆跡、當前筆畫、錯誤及同一次嘗試都保留。開老師工具不會在自己寫時提供字形協助。寫錯後成功優先顯示「你再試成功咗！」。已接納筆畫保留，毋須由頭重寫。求助或擦除都不扣分，程式亦不設分數、連勝或排名。跟寫整字完成後顯示綠色大圓圈；分件完成不出圓圈、不加星。從背景或老師工具返回後還原完成字形，不重新接受書寫或重複獎勵。有提示完成及自己完成保留清楚文字及原有勾號慶祝。減少動態效果設定會保留靜態回饋。這些回饋只描述當次操作，不代表已掌握筆順或專心程度。

新練習不顯示星數。跟寫及自己寫完成整字後都保留完整綠圈，等待孩子按下一步。


小挑戰固定顯示完整淡色目標字形，自由記錄原筆跡，不使用筆畫配對判斷答案。選詞後按「開始」才可書寫及計時，每頁一字，中途按「下一個字」，最後按「交答案」一次提交整個詞語並返回選單；卡片顯示「已完成」。沒有跳過按鈕。「提示」在原格播放當前字的筆順，保留原筆跡，另記提示使用；不會自動提交或判對。提示播放使用內置已校訂字庫，離頁、背景、換字或再次按提示會取消舊播放。老師確認字形正確後才顯示綠色 O。

詞語用時只從按「開始」後在前景書寫頁累積，包含主動觀看提示的時間；選單、背景和儲存失敗期間不計。返回同詞或重新載入後要再按開始，保留已累積時間，沒有以實際鐘錶推算。舊未交原稿保留筆跡與原有總時間，未知的舊詞語時間不平均分配，教師只看到「續寫用時」。所有新原卷以 `presentationMode: 'copy'` 記為看字寫，即使班級原有不可變的題型是聽詞寫。已封存舊原卷維持舊題型。

每次落筆完畢會把全部取樣點存入 IndexedDB。返回、提交一字及封存整份原卷都先等待保存成功。儲存失敗時保留畫面原稿並阻止離開；網絡失敗時保留封存原卷供相同內容重試。首頁「繼續本機小挑戰」可恢復原來題目和題型。班級重新開頁要先確認暱稱，不會直接顯示上一位的筆跡。

班級測驗使用獨立 Worker 與 D1。老師直接開服務的 `/teacher`，或在學生頁設定範圍後按「用以上範圍開班級測驗」。老師和學生都不用帳戶。班級固定題目、指定位置和題型；同學輸入班級碼及暱稱加入。每名成員第一份完整終結原卷是正式成績，其後練習或情境作品不會取代原卷。

原筆跡只供該成員及開班瀏覽器取回。老師可重播筆跡，逐字標示「待批改」、「O 正確」或「再練習」，另記筆順是否需要練習。字形正確一字一分，未批改不是正確。全部字都批改後才可排名。老師明確公布班級榜後，同班已交卷同學可見暱稱、分數和名次；舊聽詞寫與新看字寫分開排名。同分同名次，不用時間決勝。老師修訂原卷批改會更新已公布的分數；過期批改版本會被拒絕，須重新載入。老師可見每詞用時及是否使用提示；學生書寫頁只顯示當前詞語用時。

本機小測可由老師直接批改和重播。「下一位同學」只在封存後提供，建立另一份本機原卷，保留上一份給「本機原卷」查看。本機原卷不混入班級成員快取。它沒有學生身份驗證，應由老師管理共用裝置。正式交卷後可另做「跟住練習」，或用六項內置詞語完成情境小挑戰。作品卡保留挑戰原筆跡、圖片及介紹用途，與正式分數分開。

班級從建立起 24 小時到期，服務拒絕所有讀寫。老師可提早刪除整班，連同成員原卷和批改一併刪除。建立新班或呼叫到期清理端點，每次最多刪除 10 個已到期班級，截止時間只由伺服器決定。定時背景清理尚未啟用，不承諾精確刪除時間或供應商備份同時消失。裝置的原稿、原卷及挑戰亦在到期後停止顯示，下一次執行時清理。

暱稱和瀏覽器憑證不是已驗證帳戶。同名不會接管他人紀錄，遺失憑證不能靠暱稱取回。老師權限由開班瀏覽器自動保存，清除瀏覽器資料後不能恢復。班級最多 100 人，每個開班瀏覽器最多同時 10 班，全服務最多同時 100 班。原卷每份最多 1,800,000 bytes、200,000 點、每字 256 筆；超出時保留當前原稿，必須在該字提交前處理，沒有自動刪點或縮減筆跡。班級及全服務的原筆跡容量分別為 64 MiB 和 256 MiB。

服務地址仍為 `https://zimanman-classroom-1023.lokyau65.chatgpt.site`。單檔版保留本機測驗及批改，跨平板班級功能使用網上頁面。服務 API、建置及本機 D1 驗證見 [classroom-service/README.md](classroom-service/README.md)。程式提交與實際部署分開記錄。

既有練習仍使用版本 4 和 Hanzi Writer。練習原筆跡只留在當節記憶體，不寫入舊歷史；版本 1 至 3 紀錄仍可讀取。新小挑戰使用版本 3 assessment 原卷及版本 2 assignment，版本 2 已封存原卷仍可讀取。舊錯誤次數和時間成績不會轉成老師字形分數。

學生頁使用「小挑戰」，「情境小挑戰」仍是另外的作品活動。老師設定與批改用語、儲存版本及 API 名稱不變。

推送至 `main` 會自動執行 `.github/workflows/pages.yml`。流程先用 Node.js 24 執行現有行為測試及字庫檢查，全部通過後才將 `dist/` 部署到 GitHub Pages。GitHub 儲存庫嘅 Pages 發佈來源須設為 GitHub Actions。亦可在 Actions 頁面手動執行流程。網站不需要伺服器程式或額外建置。

`index.html` 與 `leaderboard.html` 的本機程式及樣式網址包含內容版本，避免新版頁面讀到舊快取。更改後執行 `node scripts/version-assets.cjs`；版本為統一 LF 換行後 SHA-256 的首 12 字。單檔產生器可處理這些版本網址。

執行以下指令檢查邏輯及重新產生單檔版。

```powershell
node scripts/version-assets.cjs
node scripts/standalone.cjs
node --test tests/*.test.cjs
node classroom-service/build.mjs
node dist/data/self-check.mjs
```

老師工具可編輯詞語及每節指定字次。練習紀錄使用版本 4，新測驗另用版本 3 assessment，並只記指定位置。原有版本 1 的完整範圍及版本 2 的已選位置紀錄仍可讀取，不會改寫為新版。套用新設定前會先核對完整選字設定，錯誤或零選字不會結束目前有效練習。本機歷史只留喺目前瀏覽器及網站網址。共用平板使用者可能查看，清除瀏覽器資料後亦會遺失。原本 Sites 網址嘅歷史不會自動轉移到 GitHub Pages，不同平板或瀏覽器之間亦不會同步本機歷史；跨平板班級榜則另外儲存已交卷結果。瀏覽器拒絕儲存時仍可練習，畫面會說明未儲存。

「自己完成」只代表該次無開提示完成平板筆畫配對，不能證明默寫、紙筆書寫或學習成效。筆畫配對容許較大偏差，只供練習回饋，並非書寫字形評分。紀錄保留之前提示、重試、未完成及老師略過嘅嘗試。收起字形期間亦會遮住介面其他位置嘅目標字；練習的獨立試寫開老師工具則先計為提示。新測驗的老師批改在正式提交後進行，重新載入可明確選擇恢復原稿。練習重開網頁仍保留原有未完成紀錄規則。
