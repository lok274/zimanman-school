# 字慢慢

供學校平板使用嘅繁體中文筆順練習。孩子先揀詞語，再逐字看示範、跟寫及收起字形試寫。介面有可選粵語聲音、起筆提示、休息及老師協助略過。程式不錄音，不記學生姓名，不設帳戶。

GitHub Pages 網頁入口為 [字慢慢](https://lok274.github.io/zimanman-school/)，任何人都可透過連結開啟，不需要 GitHub 帳戶。原始碼放喺 [lok274/zimanman-school](https://github.com/lok274/zimanman-school)。

Android 平板請用更新版 Chrome，iPad 請用 Safari，直接開啟上述 HTTPS 網址。iPad 需要 iPadOS 15.4 或以上，因為老師工具及休息視窗使用該版本開始支援嘅 [原生 dialog 功能](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。書寫區可用手指或觸控筆操作，實際觸控筆及掌壓排除表現需要在學校裝置測試。粵語聲音視裝置及瀏覽器有冇提供粵語語音而定，請在上堂前按「聽詞語」確認。

直接開啟 `dist/standalone.html`，可用內置六項詞語。部分平板嘅檔案預覽器未必執行下載嘅 HTML，平板建議用上面嘅網站。亦可用任何靜態網頁伺服器提供 `dist/`。新增字詞可能需要上網載入字庫。

內置六項詞語使用純白背景嘅 AI 生成寫實圖片，並非實地拍攝照片。詞語卡及練習頁共用同一圖片；新增詞語或圖片未能載入時顯示原有圖示。單檔版已嵌入六張圖片。圖片內容、檔案及完整生成提示詞見 [圖片說明](圖片說明.md)。

上堂前，老師先開「老師工具」，在各詞語內逐字選擇，再按「套用並開始新一節」。預設只練第一項詞語的第一個字，建議每次 1 至 2 字；可選 1 至 6 項詞語內最多 48 個字。畫面會先顯示已選字數。同字出現在不同位置會分開練，例如「推來推去」第一、三字的「推」。只選第三字時仍保留完整詞語作背景，但只需完成該字，不會把其他三字列為待練。孩子自己揀詞語先後，揀詞畫面顯示指定總數及已處理數；老師略過仍分開記錄，並非完成書寫。最後一個指定字處理後，孩子按下一步才看紀錄。完成後先休息，再從今次練過的字揀一個用紙筆試寫，方便老師觀察能否離開提示書寫。

練習區上方有獨立「聽指令」按鈕，只在孩子按下時朗讀畫面上的同一句指令。「聽詞語」仍用來讀詞語及目標字，兩者用途分開。聽操作指令不算書寫提示，不會改動嘗試結果。程式只使用裝置提供的粵語聲音，缺少語音、瀏覽器封鎖或播放錯誤時顯示文字說明，不改播普通話。轉步驟、休息、開老師工具、轉到背景或離開網頁會停止語音。普通筆畫回饋不會打斷仍適用的操作指令。實際可聽度仍須在課堂平板確認。

練習頁將重播、單畫示範、字形提示、重試、音效及畫面設定收進同一個「更多工具」。詞語讀音、聽指令、當前筆畫提示、休息及返回仍可直接操作。已刪去口號及重複說明。每次開啟預設使用「精簡畫面」，收起圖片、例句及較長說明，保留簡短原詞背景、詞語語音、目前步驟、操作指令、書寫格及所有必要控制；指定字數仍可在揀詞畫面查看。橫向平板會把書寫格和操作按鈕並排。開啟「更多工具」，按「精簡畫面」可切回完整背景，再按可收起。切換只改顯示，不重開書寫格、不重設筆畫、不新增提示或嘗試。獨立試寫時兩種畫面同樣隱藏目標字。休息仍在練習區上方，返回仍在頁尾左邊。

練習標題及操作指令各自置中，字體均比原有尺寸加大 10pt。平板精簡畫面按可用高度調整方形書寫格；展開工具、完整畫面或較小視窗仍可正常捲動。

練習時可用頁尾左邊嘅返回按鈕退回上一個步驟。「自己試」及完成畫面返回同一個字嘅新一輪跟寫，跟寫返回睇筆順，睇筆順或載入畫面返回詞語選擇。老師若在字形未載入前略過，返回時會先重新載入。返回後由該步驟起點重新練習。之前嘅提示、未完成嘗試及完成結果會保留，返回本身不會得到完成獎勵。

「休息一下」放喺練習區上方，使用有邊框嘅大按鈕，字體比原本增加 6 pt。休息後按「我準備好喇」會返回原本步驟，保留練習進度。

每畫被書寫工具接納後，書寫格下方會即時顯示勾號及畫數。寫錯後再成功會指出已完成重試嗰畫。求助、重新試或休息都不扣分，程式亦不設分數、連勝或排名。跟寫完成、有提示完成、自己完成各有清楚文字，並有同樣短暫嘅勾號慶祝。減少動態效果設定會保留靜態勾號。這些回饋只描述當次操作，不代表已掌握筆順或專心程度。

「完成提示聲」每次開網頁都預設關閉，由學生自行開啟。開啟後只在完成一個字時播放短聲，普通筆畫不會發聲。裝置靜音、瀏覽器限制或音效未準備好時，畫面回饋照常，程式不會之後補播。休息、開老師工具、轉步驟、轉到背景或離開網頁會停止正在播放嘅提示聲及慶祝動態。實際音量及聲音能否播放，需要在學校平板試用。

推送至 `main` 會自動執行 `.github/workflows/pages.yml`。流程先用 Node.js 24 執行現有行為測試及字庫檢查，全部通過後才將 `dist/` 部署到 GitHub Pages。GitHub 儲存庫嘅 Pages 發佈來源須設為 GitHub Actions。亦可在 Actions 頁面手動執行流程。網站不需要伺服器程式或額外建置。

`index.html` 的 `app.js` 及 `styles.css` 網址包含內容版本，避免新版頁面讀到舊快取。更改這兩個檔案後，測試會列出應更新的網址；版本為統一 LF 換行後 SHA-256 的首 12 字。單檔產生器可處理這些版本網址。

執行以下指令檢查邏輯及重新產生單檔版。

```powershell
node --test tests/*.test.cjs
node scripts/standalone.cjs
node dist/data/self-check.mjs
```

老師工具可編輯詞語及每節指定字次。新紀錄使用版本 2，只記指定位置；原有版本 1 紀錄仍按當時的完整詞語範圍顯示，不會改成新範圍。套用新設定前會先核對完整選字設定，錯誤或零選字不會結束目前有效練習。紀錄只留喺目前瀏覽器及網站網址。共用平板使用者可能查看，清除瀏覽器資料後亦會遺失。原本 Sites 網址嘅紀錄不會自動轉移到 GitHub Pages，不同平板或瀏覽器之間亦不會同步。瀏覽器拒絕儲存時仍可練習，畫面會說明未儲存。

「自己完成」只代表該次無開提示完成平板筆畫配對，不能證明默寫、紙筆書寫或學習成效。筆畫配對容許較大偏差，只供練習回饋，並非書寫字形評分。紀錄保留之前提示、重試、未完成及老師略過嘅嘗試。收起字形期間亦會遮住介面其他位置嘅目標字；開老師工具則先計為提示。重開網頁會將該分頁未完成嘅上一節列為未完成，再開始新一節。

初始十一個字已附本機資料。`草`、`密`、`來` 按教育局圖示調整，詳見 `dist/data/provenance.json` 及 `NOTICE.txt`。字形風格仍可能不同，請按學校教法核對。新增字未經香港逐畫核對。字庫採 Arphic Public License。Hanzi Writer 固定為 3.5.0，採 MIT 授權。單檔版包括授權全文。
